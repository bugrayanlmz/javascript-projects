# JavaScript Projects

Small projects for practicing JavaScript, DOM manipulation, events, and asynchronous programming. Built with plain HTML, CSS, and JavaScript.

## Projects

- [Expanding Cards](expanding-cards): Click an image panel to expand it.
- [Progress Steps](progress-steps): Navigate a four-step progress indicator with Previous and Next buttons.
- [Load Images](load-images): Load three images sequentially using Promises, displaying each for two seconds.

## Run Locally

```bash
git clone https://github.com/bugrayanlmz/javascript-projects.git
cd javascript-projects
```

Open the `index.html` file inside any project folder in your browser. No dependencies or build step are required. Expanding Cards loads its images from Unsplash and needs an internet connection.
